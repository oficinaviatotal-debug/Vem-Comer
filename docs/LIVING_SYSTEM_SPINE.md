# Vem Comer — Living System Spine

## Purpose
The product is a living system: it continuously observes technology, foodtech, devices, connectivity, UX, security, regulation, operations and commercial outcomes, then proposes, tests and safely adopts improvements.

## Operating loop
OBSERVE -> DETECT -> CONTEXTUALIZE -> HYPOTHESIZE -> SIMULATE -> TEST -> VALIDATE -> GATE -> IMPLEMENT -> MEASURE -> LEARN -> RENEW.

## Agent organization
- Executive orchestrator: prioritizes missions and enforces authority boundaries.
- Intelligence scout: continuously discovers public/authorized signals.
- Design evolution: maintains original visual system, accessibility, responsive behavior and interaction quality.
- Technology evolution: evaluates platforms, AI, payments, QR, printing, PWA, devices and connectivity.
- Security/compliance: detects vulnerabilities, privacy and regulatory changes.
- Acquisition/conversion: intent -> contextual offer/page -> CTA -> activation -> retention.
- Operations brain: coordinates catalog, orders, stock, kitchen, delivery, payments, costs and support.
- Margin/capacity intelligence: connects demand, stock, CMV, pricing, capacity and cash outcomes.
- Learning agent: converts outcomes and failures into reusable, regression-testable knowledge.

## Multi-input contract
Every major workflow should accept, where applicable: voice, text, image/photo, document/PDF, spreadsheet, structured data/API and code.

## Second brain
Store decisions, evidence, experiments, operational patterns, failures and outcomes with provenance, freshness and scope. Keep Vem Comer operational data independent from Vem Trabalhar while allowing authorized relationship/demand events.

## Design evolution
Use public/authorized references as learning inputs. Extract principles and tokens; do not copy protected brand identity or code.

## Operations intelligence
The system should be able to represent processes, SOPs, checklists, workflows, timelines, bottlenecks, risk, capacity, root cause, customer journey, decisions, KPIs and before/after results.

## Success definition
The system continuously becomes faster, simpler, more compatible, more resilient and more useful without creating uncontrolled complexity.
